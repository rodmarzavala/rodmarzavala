## About

Engineering Lead & DevOps with 15+ years shipping backend systems and leading distributed teams. Currently the tech lead at **Fundamental**, a Venture Studio based in Guatemala, where I architect and deliver the software behind their portfolio ventures — from zero to production.

I focus on technical leadership — architecture decisions, team delivery, and keeping the DevOps side healthy. Most of my professional work lives in private repos; the public ones are deliberate open source contributions.

- 🏗️ **Backend**: PHP (Symfony · Laravel), Node.js, Go
- ☁️ **Cloud & DevOps**: AWS, DigitalOcean, GitHub Actions, Docker
- 👥 **Leadership**: Distributed teams across Latin America
- 🌎 **Reach**: Latin America (Fundamental) · Europe — France & Poland (PragaWebStudio)

## Open Source

### 🧾 infile-php — Electronic Billing for Guatemala (SAT/FEL)

PHP wrapper for the [INFILE](https://infile.com.gt) API, enabling FEL (Factura Electrónica en Línea) generation for Guatemalan businesses. The only open source PHP ecosystem for this integration.

| Repo | Stack |
|---|---|
| [`infile-php`](https://github.com/rodmarzavala/infile-php) | Vanilla PHP — core library |
| [`infile-php-symfony`](https://github.com/rodmarzavala/infile-php-symfony) | Symfony bundle |
| [`infile-php-laravel`](https://github.com/rodmarzavala/infile-php-laravel) | Laravel package |
| [`infile-php-wordpress`](https://github.com/rodmarzavala/infile-php-wordpress) | WooCommerce integration |

### 💳 recurrente-sdk — Payments SDK (Node.js)

Unofficial TypeScript SDK for [Recurrente](https://recurrente.com), a payment gateway operating in Guatemala and Central America. Typed, composable, ready for production.

→ [`recurrente-sdk`](https://github.com/rodmarzavala/recurrente-sdk)
